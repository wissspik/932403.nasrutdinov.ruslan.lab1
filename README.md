# Лабораторная работа №3

Адаптивная страница «Волонтёр и социальный активист» на основе результата лабораторной работы №2.

## Данные

- Группа: 932403
- Студент: Nasrutdinov Ruslan
- Вариант: 13
- Тема: «Волонтёр и социальный активист»

## Что реализовано

- Горизонтальное адаптивное меню на Flexbox с переходами к разделам страницы.
- Три карточки «Текущих акций»: в каждой есть название, дата, роль и ссылка.
- CSS Grid с тремя карточками «Роли в команде» и иконками.
- Адаптивность: карточки и grid меняются с 3 до 2 и 1 колонки; нет горизонтальной прокрутки.
- Семантические `header`, `nav`, `main`, `section`, `article`, `time`, `dl` и доступная навигация с клавиатуры.
- Контрастная палитра, заметные состояния фокуса и ссылка быстрого перехода к содержимому.

## Файлы

- `index.html` — структура страницы.
- `style.css` — стили Flexbox, Grid и медиазапросы.
- `images/avatar.svg` — аватар из лабораторной работы №2.
